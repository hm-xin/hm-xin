Real Estate Brokerage Website Freelance Client
WordPress & Elementor — Oct 2025 to present

Overview

A responsive website for a real estate brokerage client, built to present their brokerage, appraisal, and documentation services through a clear, conversion-oriented user experience.

What I built

  • Full responsive site in WordPress, customized with Elementor.
  • Interactive world map using Leaflet.js to showcase the brokerage's reach.
  • Video testimonials integrated into the page flow to build trust with visitors.
  • Custom HTML, CSS, and JS for layout and interaction details Elementor couldn't handle out of the box.
  • Ongoing frontend troubleshooting, performance checks, and debugging as the site evolves.

What I learned

This was my first time owning a client project solo — from build to ongoing maintenance. It taught me how to translate a client's business goals into a site structure, and how much of real freelance work is troubleshooting and small fixes after launch, not just the initial build.

StackWordPress, Elementor, Leaflet.js, HTML/CSS/JS

Job Request System School Project
Web Application / Management System

The problem

Managing job requests manually made it difficult to keep track of incoming requests, assigned personnel, progress, and completed work.

The solution

A web-based system that organizes job requests into a structured workflow, allowing users to submit, manage, update, and monitor requests from a centralized interface.

Key features

  • Job request submission, tracking, and status management
  • User management and admin dashboard/overview
  • Database-driven records with full request history

What I learned

This project helped me understand how a real-world management system is structured — from capturing user input and storing records to processing requests and presenting information through an administrative interface. This is also the project I later carried into my internship at Jose R. Reyes Memorial Medical Center.

Parking Management System School Project
Web & Application-Based Management System

The problem

Traditional parking management involves manual recording and monitoring, making it difficult to determine availability and maintain organized parking records.

The solution

The system digitizes the parking management process by providing an organized interface for managing parking information and monitoring parking activity.

Key features

  • Parking space management and availability monitoring
  • Booking/reservation workflow with user management
  • Database-driven parking records, responsive interface

What I learned

This project gave me practical experience designing a system around a physical, real-world process. Instead of simply displaying information, the application needed to represent availability, users, transactions, and system states in a way that users could understand and manage.
